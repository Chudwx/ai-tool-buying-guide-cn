# AI 工具与数字服务选购清单（中文）

这份清单帮助个人和小团队在购买 AI 工具或数字服务前核对需求、成本、隐私、兼容性与售后。它不替具体商家背书，也不假设所有服务适用于每个地区或账号。

## 购买前 7 项核对

1. **先定义任务**：你需要写作、编程、图像、资料分析，还是团队协作？
2. **核对具体商品**：确认购买的是账号、订阅、点数、服务还是其他交付物。
3. **看总成本**：检查币种、周期、续费、额外费用和退款条件。
4. **确认使用资格**：阅读服务条款、地区限制、年龄与账号要求。
5. **核对交付流程**：确认开通时间、需要提供的信息、失败处理和客服联系渠道。
6. **保护账号安全**：不要向第三方提供密码、验证码或恢复码；优先使用官方支持的授权方式。
7. **留存凭证**：保存商品说明、订单号、付款凭证和售后沟通记录。

## 简单比较表

| 维度 | 购买前要回答的问题 |
| --- | --- |
| 需求 | 它解决的具体任务是什么？ |
| 价格 | 一次性还是周期性收费？是否自动续费？ |
| 兼容性 | 我的地区、设备、账号和支付方式是否支持？ |
| 隐私 | 服务会收集哪些资料？如何删除或导出？ |
| 售后 | 出问题时如何联系？退款条件是什么？ |
